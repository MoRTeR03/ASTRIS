# ASTRIS — scope для практики

## Кодове ім'я
ASTRIS — Advanced Satellite Tracking & Real-time Interactive System.

## Офіційна назва
«Вебсистема інтерактивного моніторингу та візуалізації орбітального руху штучних супутників Землі».

## Мета
Розробити вебзастосунок для інтерактивного відображення актуального орбітального положення штучних супутників Землі, аналізу їх видимості відносно положення користувача та візуалізації орбітальних характеристик.

## Основні задачі
- інтеграція зовнішнього джерела актуальних орбітальних елементів;
- серверне кешування та нормалізація OMM;
- SGP4/SDP4-розрахунок поточного положення;
- 2D/3D геовізуалізація;
- приблизне визначення спостерігача за IP;
- ручна корекція координат;
- фільтрація GNSS/Starlink;
- пошук та перегляд характеристик супутника;
- визначення азимуту, кута піднесення і дальності;
- відображення орбіти вибраного об'єкта.

## Не входить у v0.1
- керування космічними апаратами;
- прогноз зіткнень;
- професійна flight-dynamics валідація;
- високоточна GNSS-геодезія;
- власна база Space-Track;
- мобільний застосунок.
