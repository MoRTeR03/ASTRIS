# Походження ASTRIS

ASTRIS створено як самостійний навчально-практичний WEB-проєкт на базі власних попередніх напрацювань orbital/map підсистеми IRMAS.

З IRMAS концептуально перевикористано:

- підхід до MapLibre 2D / Globe;
- SGP4-візуалізацію орбітальних об'єктів;
- колірну семантику GNSS-сузір'їв;
- OLED/dark операторський стиль;
- серверний cache-first підхід до CelesTrak;
- принцип відображення повної орбіти вибраного супутника.

ASTRIS не є копією IRMAS і не залежить від його runtime. Новий застосунок має окремі `client`, `server`, API, IP-observer, Starlink-каталог і власний життєвий цикл.
